# This is a RECORD of a known-good environment, not a curated minimum and not
# a version upgrade decision. Before this file existed, setup.sh installed
# openai-whisper and mlx-whisper unpinned, so there was no way back if a pip
# resolution changed underneath the project. These are the exact versions
# confirmed (via a read-only `pip freeze` against the working .venv) to
# install and run correctly together, and nothing here should move without
# deliberately re-verifying the new versions against a real transcribe/repair
# run.
#
# Only the two packages setup.sh installs directly are pinned. Their
# transitive dependencies (torch, numpy, numba, mlx, mlx-metal, and the rest)
# are left to the resolver: setup.sh supports Python 3.9-3.13 across macOS,
# Linux, and both Apple Silicon and Intel, and a transitive closure pinned
# from a `pip freeze` on one interpreter/platform can be unsatisfiable on
# another (e.g. numba wheels lag new CPython releases by months - see
# setup.sh's MAX_TESTED_PY_MINOR comment). Pinning only the direct
# dependencies avoids shipping a requirements file that fails to install
# somewhere this repo is supposed to work.
#
